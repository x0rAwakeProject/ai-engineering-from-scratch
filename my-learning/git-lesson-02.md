# Урок 02 — Git & Collaboration

Я изучаю систему контроля версий Git.

Что я узнал:
- Git сохраняет историю изменений проекта.
- Команда git add подготавливает файлы.
- Команда git commit сохраняет изменения локально.
- Команда git push отправляет коммиты на GitHub.
- Ветки позволяют работать независимо от main.
